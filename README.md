# Retail Management System

A Python-based academic project developed for CECS218 at the University of Jeddah.

## Overview
The system manages customers, products, memberships, inventory, and orders through an interactive console application.

## Features
- Customer, Member, and VIP Member management
- Product and bundle management
- Inventory tracking
- Order processing
- Membership discounts
- File handling
- Data validation
- Custom exception handling

## Technologies
- Python
- Object-Oriented Programming (OOP)
- File Handling
- Exception Handling
